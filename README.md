## 🇧🇷 Português

**Descrição:** Ferramenta em Python para leitura, mapeamento estrutural e organização de dados em arquivos CSV e texto.

**Objetivo:** Facilitar a etapa de inspeção e limpeza de dados (Data Wrangling), permitindo mapear rapidamente a estrutura do arquivo CSV, identificar inconsistências, contagens e gerar resumos estatísticos sem a necessidade de abrir o arquivo em editores pesados.

---

## 🇺🇸 English

**Description:** Python tool for reading, structural mapping, and data organization in CSV and text files.

**Objective:** To streamline the Data Wrangling and inspection phase by allowing users to quickly map CSV file structures, detect data inconsistencies, compute row counts, and generate statistical summaries without opening heavy spreadsheet applications.
